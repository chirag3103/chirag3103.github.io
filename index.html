NOW NEXT BEFORE AT WORK AND AT HOME
NOW
DEC 2024 – NOW

Senior AI Platform Engineer, Tech Lead · Hinge Health

On the AI platform team behind Robin, Hinge Health's AI care assistant.

  • Led the move from a monolithic AI agent to a modular LangGraph system, and broke a monolithic context builder into independent, testable data modules.
  • Lead the next-generation exercise recommendation engine as PM and engineer. It is one shared capability any agent can call, it moved from rules to conversational, personalized recommendations, and it asks before it changes anything.
  • Made clinical alignment part of shipping: a sign-off loop with clinical partners, claims grounded in vetted content, fabrication paths closed, and judges that track clinical accuracy and safety over time.
  • Designed the assistant's evaluation suite on LangSmith: the judges, the dataset flow, and one lean whole-conversation trace that every agent emits.
  • Architected RAG and vector search infrastructure on Databricks.
  • Built multimodal LLM features for text and voice, with HIPAA-compliant integrations.
  • Own release engineering for a multi-team AI service, from release branches to continuous deployment. I run AI coding agents as a supervised team, so every PR is agent-reviewed and verified before a person sees it.
WHERE THE PLATFORM IS GOING
NEXT

Platformization

  • Turning the agent building blocks into packages other teams can build on: one place to choose an LLM provider, and a base agent with tracing built in.
  • Agents that can't be pointed at the wrong person's data. Identity comes from a verified token, never from a parameter the model fills in.
  • Evals that say what to fix, not just that something broke.
